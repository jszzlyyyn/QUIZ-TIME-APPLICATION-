# QUIZ TIME 💻

A simple quiz game developed using Java Swing for our Computer Programming 2 final project.

## About the Project

QUIZ TIME is a timed quiz game with 8 questions. Each question has four choices, and the player has 15 seconds to answer each question.

## Technologies Used

- Java
- Java Swing
- AWT

## Features

- Main menu with Play and Quit buttons
- 8 quiz questions
- Four choices for each question
- 15-second timer for every question
- Score tracking
- Immediate feedback for correct and wrong answers
- Timer progress bar
- Final score and percentage
- Play Again option
- Main Menu option

## Project Purpose

This project was simple and created as our final project for Computer Programming 2 to practice Java programming and GUI development using Java Swing.
